# AI memory

What a senior developer new to this project needs to know and cannot get from the code.

## How to use this file

- **Add:** major decisions, business constraints, traps, approaches tried and rejected, and non-technical knowledge a senior newcomer needs.
- **Do not add:** anything derivable from code, temporary task status, or personal preferences.
- **Maintain:** update an outdated entry instead of adding a contradicting one. Over budget, consolidate.
- **Commit:** in the same change as the related work.

Entry format, under the matching heading below. Keep one `Type`.

```markdown
### YYYY-MM-DD: Short title
Type: decision | constraint | trap | context | rejected
Why: ...
Applies to: ...
```
